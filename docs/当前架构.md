# 当前架构说明

## 目标

最终产品是原生微信小程序。H5 端保留为浏览器内测和业务回归测试床，不作为微信小程序的替代品。

## 组件

```text
miniprogram/  原生 WXML/WXSS/TypeScript，小程序唯一导入目录
       │ wx.request / wx.login
       ▼
server/       Node 22.9+ HTTP API
       │
       ▼
SQLite        单实例、WAL、持久化磁盘

shared/       绑定码、积分、状态机、权限和接口契约的唯一规则源
h5/           Vite + TypeScript 浏览器测试床
```

## 数据和身份

- 服务端是业务规则和权限的最终边界，前端隐藏按钮不构成安全控制。
- 小程序通过 `wx.login` 获取临时 code，服务端再通过微信 `code2Session` 解析 OpenID。
- 数据库当前保存加盐身份哈希，不保存可直接发送订阅消息的原始 OpenID。
- 家长第一次绑定后，后续同一 AppID 下的登录可以恢复绑定；切换 AppID 或从 H5 开发身份切换到真实微信身份，需要重新绑定一次。
- 图片目前以 dataURL 写入 SQLite，仅适合小班内测；扩容前迁移对象存储。

## 共享代码规则

修改 `shared/src/` 后执行：

```bash
npm run build:shared
npm run sync:shared
```

`miniprogram/shared/` 是自动生成的运行时副本，不能手改或删除单个文件。设计令牌由 `npm run build:wxss` 从 H5 样式生成到 `miniprogram/styles/tokens.wxss`。

## 当前明确不包含

- 微信订阅消息的授权、发送、重试和定时 worker。
- 多实例部署和横向扩容。
- 生产级对象存储、删除策略和完整隐私权利流程。
- 真机渲染和所有微信审核材料。
