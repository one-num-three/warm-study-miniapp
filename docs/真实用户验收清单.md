# 真实用户验收清单

## 测试准备

- 一台 iOS 和一台 Android 真机。
- 一个负责人账号、一个老师账号、至少三个测试家长账号。
- 三个测试学生、三种商品、包含文字和图片的作业。
- staging API 使用 HTTPS，开发者工具打开合法域名校验。
- 测试数据与生产数据完全隔离。

## 负责人

- [ ] 登录后进入今日看板。
- [ ] 新增学生并生成绑定码。
- [ ] 绑定码预览脱敏，重置后旧码失效。
- [ ] 审核/拒绝家长绑定申请。
- [ ] 新增老师并分配最小权限。
- [ ] 上架商品、设置库存和兑换限制。
- [ ] 查看审计日志和积分对账。
- [ ] 停用老师后其旧会话失效。

## 老师

- [ ] 只看到自己被授予的学生和功能。
- [ ] 查看当天作业并逐项标记完成/未完成。
- [ ] 未完成时填写原因。
- [ ] 标记到班、辅导中、待接和已接走。
- [ ] 发送接娃提醒后看到真实发送状态。
- [ ] 无权查看绑定码、审计或负责人设置时，接口和页面都拒绝。

## 家长

- [ ] 第一次通过绑定码确认脱敏姓名。
- [ ] 退出并重新打开后无需重复输入绑定码。
- [ ] 查看今日状态和作业。
- [ ] 提交文字作业和图片作业。
- [ ] 查看积分、排行榜、兑换商店和兑换记录。
- [ ] 查看错题并上传有效内容。
- [ ] 两位家长使用同一绑定码时权限和数据一致。
- [ ] 拒绝隐私授权或订阅授权后，页面仍有清晰可用的降级路径。

## 弱网和异常

- [ ] 重复点击不会重复提交、重复扣分或重复扣库存。
- [ ] 网络中断后有重试提示，不显示虚假成功。
- [ ] token 过期后能重新登录。
- [ ] 服务器重启后数据仍在。
- [ ] 恢复备份后作业、积分、商品和审计记录一致。
- [ ] 新的一天不会显示昨天的提醒。
- [ ] 不允许对未到班或已接走学生发送接娃提醒。

## 放行条件

所有 P0 项通过、`npm test` 和 `npm run test:e2e` 返回 0，且至少三个家庭连续使用三天没有 P0/P1 缺陷，负责人和老师共同签字后，才进入体验版或正式审核。
