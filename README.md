# 暖芽辅导班

面向小型课后辅导班的原生微信小程序。家长查看孩子当天情况、提交作业和查看积分；老师处理作业、到班和接娃；负责人管理学员、商品、权限和审计。

当前仓库同时保留一个 H5 业务测试床。最终发布目标是微信小程序，H5 只用于内测、回归和接口流程验证。

## 发布状态

当前发布基线：`main` / `c0c3879`（已推送到公开仓库）。完整集成分支是本次合并前的工作分支，不再作为日常入口。

核心业务已经完成，可以做受控内测；公开上线前还必须完成真实 AppID、HTTPS 合法域名、生产账号初始化、微信订阅消息、隐私授权、备份恢复和真机验收。

完整上线计划和验收门槛统一见：[docs/上线执行计划.md](docs/上线执行计划.md)。

## 本地开发

要求 Node 22.9+，建议固定到已经验证过的 Node 22.x 版本。

```bash
npm install
npm run dev
```

H5 默认地址为 `http://localhost:5173`，后端默认端口为 `8787`。本地演示数据只能用于开发环境，不得复制到生产数据库，也不得复用固定演示密码。

## 构建和检查

```bash
# 编译共享规则并同步小程序运行时文件
npm run build:shared
npm run sync:shared

# 生成小程序设计令牌并做静态校验
npm run build:wxss
npm run check:mp

# 构建 server 和 H5
npm run build

# 发布前质量门禁
npm run typecheck
npm test
npm run test:e2e

# 删除可重新生成的 dist 和 E2E 产物（不删数据库、文档和微信配置）
npm run clean
```

`npm test` 和 `npm run test:e2e` 必须以退出码 0 结束，才能进入发布候选版本。

## 用微信开发者工具打开

只导入仓库中的 `miniprogram/`，不要导入仓库根目录。当前 `main` 已包含完整集成版本，直接使用根目录下的 `miniprogram/`。AppID、API 地址、合法域名和 `urlCheck` 的正式配置见[上线执行计划](docs/上线执行计划.md)。

## 产品能力

- 家长绑定、多个家长、每日作业和作业照片。
- 到班、辅导中、待接、已接走状态。
- 积分奖励、排行榜、商品兑换和撤销。
- 错题集。
- 老师权限、负责人后台、绑定审核、系统设置、审计和积分对账。

微信 OpenID 登录架构已经接入：家长第一次绑定后，真实生产配置正确时，后续登录可以找回同一账号，不必重复输入绑定码。H5 的开发设备身份与真实微信 OpenID 不会自动合并，切换 AppID 后需要重新绑定一次。

## 当前明确边界

- 接娃提醒目前只记录站内提醒，尚未完成真实微信订阅消息发送。
- 图片当前走 base64 并写入 SQLite，适合小班内测；扩大规模前应迁移对象存储。
- 后端是单实例 SQLite，必须使用持久化磁盘和备份，不支持直接横向扩容。
- 小程序的真实渲染、wx.login、图片和 iOS/Android 真机验收必须在微信开发者工具中完成。

## 重要安全规则

- 真实 AppSecret 只放服务端环境变量，不能写入小程序代码、Git 或日志。
- 生产环境禁止自动演示 seed 和快速登录。
- 生产数据库与本地演示数据库分离。
- 没有真实微信发送结果时，不得把提醒显示为“已通知家长”。
- 儿童姓名、作业、错题图片和家长关系属于敏感业务数据，发布前必须完成隐私政策、授权、删除和保留期限说明。
