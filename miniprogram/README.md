# 暖芽辅导班原生微信小程序（本地演示版）

## 打开方式

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本仓库的 `miniprogram/` 目录。
3. 使用测试号或自己的 AppID 打开；`project.config.json` 已关闭域名校验，且本地演示不依赖云环境。
4. 编译后从“今日”页面切换家长、老师和负责人角色，验证不同功能入口。

## 已实现的演示流程

- 家长作业提交、科目选择、图片选择、老师处理和积分奖励。
- 到班、辅导中、待接、已接走状态与 30 分钟/自定义接娃提醒。
- 积分流水、余额保护、冲正、周成长排行榜。
- 商品上/下架、库存增加、现场兑换和兑换记录。
- 错题上传与订正状态推进。
- 家长绑定审核、学生停用、角色权限说明和审计记录。
- 功能导览，覆盖全部已实现功能。

## 数据说明

所有示例数据保存在当前微信客户端的本地存储中；“恢复本机示例数据”会重置本机演示数据。正式版应将 `utils/store.js` 的数据服务替换为 CloudBase 云函数，并在服务端实施角色、绑定关系、积分事务和订阅消息权限校验。
